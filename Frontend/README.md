# CMS Frontend

基于 `React + Vite + TypeScript + Ant Design` 的 CMS 前端项目。

## 启动方式

```bash
npm install
npm run dev
```

默认本地地址：`http://localhost:5173`

## 构建

```bash
npm run build
```

## 页面路由

- `/login`
- `/dashboard`
- `/users`
- `/orders`
- `/media`
- `/analytics`
- `/roles`
- `/settings`
- `/profile`
- `/logs`

## 目录结构

- `src/layouts`：后台壳层布局
- `src/router`：路由配置
- `src/pages`：业务页面
- `src/components`：复用组件
- `src/mocks`：演示数据
- `src/services`：API 抽象层
- `src/styles`：主题与全局样式
